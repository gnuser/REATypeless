REATypeless 1.2.0 — 测试说明 / Tester checklist

范围：Apple Silicon Mac 源码预览版；请先完成 README 的安装和权限步骤。
Scope: Apple Silicon macOS source preview. Complete the README setup first.

1. 切换中文 / English 界面，保存并重启，确认选择保留。
   Switch UI language, save, restart, and confirm the preference persists.
2. 点击快捷键设置，直接按组合键并保存；尝试重复组合键，确认冲突提示。
   Record and save a shortcut; try a duplicate and check the conflict message.
3. 在另一应用的句子中间放置光标，分别用按钮、全局快捷键录音并停止。
   Put the caret inside another app's sentence; test button and shortcut recording.
4. 确认文字插入原位置；再测试选中文字替换、取消录音、关闭目标输入框。
   Check insertion, selected-text replacement, cancellation, and a closed target field.
5. 说一段中文和英文，检查简体中文输出、原文复制和可选润色。
   Dictate Chinese and English; check simplified output, raw copy, and optional polishing.
6. 自动插入失败时，确认可以从历史记录复制结果。
   When insertion fails, confirm the result remains available in History.

Windows x64 checks
- npm test: includes live PowerShell bridge status, UTF-8 simplified conversion, and invalid target rejection.
- npm run build:native; npm start: allow desktop microphone access in Windows Settings.
- With Windows builds of whisper-cli/ffmpeg and downloaded models, dictate in the app scratchpad.
- In Notepad and a browser editable field, start/stop with the global shortcut. Verify the caret and selected replacement; delivery is confirmed only when the resulting document matches the expected text.
- Change field contents while recording, close the destination, or use a password field: no automatic insertion; retrieve text from History.
- Test both shortcuts and opening the main window before recording; the last external input and caret should be remembered.
- Test cancellation, clipboard restoration, unavailable runtimes, denied microphone, and tray double-click.
- npm run dist:win: inspect dist/win-unpacked; runtime DLLs and models must accompany the package.
- npm run test:integration uses Windows System.Speech with an installed English voice; test:native remains macOS-only.

Windows insertion regression fixture
- Run node_modules/electron/dist/electron.exe tests/windows-input.fixture.cjs. It opens a disposable target and separate controls process.
- Focus target textarea, then switch to controls and click Capture followed by Paste. Expect alpha 你好omega and status ok.
- Capture with Ctrl+Alt+F9 while the textarea is focused; edit its text before Paste. Expect status edited and no extra insertion.
- Focus the password field, then Capture. Expect unsupported with no token.
- Close the controls window to stop the fixture and its target. Tests use isolated .tools profiles.
